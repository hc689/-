# 壮乡乐脉·广西音乐传承创新与传播平台

## 项目简介

壮乡乐脉是由汉语言文学与设计学学生共同发起的文化创新项目，致力于利用线上媒体平台传播和AI辅助创作，推动广西民族音乐传承。项目借助AI音乐生成技术，融合现代编曲与民族音乐元素，创作出兼具传统韵味与时代特色的新民歌，吸引民歌传承人与爱好者参与。

## 核心功能

1. **AI音乐创作**：融合广西民族音乐元素，通过AI技术生成新民歌
2. **作品展示**：展示用户创作的音乐作品和广西传统民歌
3. **互动交流**：用户之间的评论、点赞、分享等互动功能
4. **个人中心**：用户管理个人信息、查看个人创作和收藏的作品

## 如何使用

1. 下载微信开发者工具
2. 导入本项目
3. 运行小程序

5. 开始使用AI音乐创作功能
6. 浏览和分享音乐作品
7. 参与互动交流
